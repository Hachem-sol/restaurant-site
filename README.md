# 🍽️ Restaurant AlKhayr

Site web vitrine moderne et responsive réalisé pour un restaurant spécialisé dans les produits de la mer.

## 📌 Présentation du projet

**Restaurant AlKhayr** est un projet de site web vitrine développé dans le cadre de mon apprentissage du développement web et de la préparation de mon portfolio professionnel.

L'objectif est de présenter le restaurant, son menu, ses coordonnées et de permettre aux visiteurs de prendre facilement contact.

## ✨ Fonctionnalités

* 🏠 Page d'accueil avec présentation du restaurant
* 🍴 Présentation du menu
* 📖 Section « À propos »
* 📞 Informations de contact
* 📍 Lien vers Google Maps
* ✉️ Formulaire de contact
* 📱 Design responsive pour ordinateur, tablette et mobile
* 🧭 Navigation avec défilement fluide
* ✨ Effets visuels et interactions CSS

## 🛠️ Technologies utilisées
